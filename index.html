How to read this

It's a Venn diagram, laid out as columns. Each column is one spot where your circles would overlap.

  1. Dots say which groups. A coloured dot means "in this group", a grey one means "not". Dots joined by a line mean "in all of these at once".
  2. The bar says how many. Taller bar, more thoughts in that exact mix. The biggest ones come first.
  3. The thoughts are listed underneath each column, so you can see exactly what's in it.
  4. The number next to a group name on the left is that group's total, counting every column it shows up in.

Click a column to see all its thoughts. Drag a thought onto another column to change which groups it's in.
